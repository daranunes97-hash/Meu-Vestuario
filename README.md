# Meu Provador

App pessoal para montar looks com as roupas do meu armário, separados por estação e estilo, só com combinações que têm coerência (cores, estampas, nível de arrumação e clima).

- **Abrir:** https://daranunes97-hash.github.io/meu-vestuario/
- **Instalar no celular:** abra o link no navegador → menu → "Adicionar à tela inicial".
- **Dados:** ficam só no celular de quem usa (localStorage `provador-v1` + fotos no IndexedDB). Faça backup em ⚙️ Ajustes.

Arquivos: `index.html` (o app), `sw.js` (funciona sem internet), `manifest.webmanifest` e os ícones (instalação).
